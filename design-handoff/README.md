# Design handoff — Ami for allNow
Everything the next team needs, no code knowledge required.

1. `SPEC.md` — required files, sizes and where they go in ServiceNow, with status.
2. `brand-assets/` — the files, named exactly as requested. `manifest.json` lists each file, size and field.
3. `wireframes/` — open the PNGs; numbered pins match the legend under each screen.
4. `reference/` — originals as received.

Open points for the receiving team: official vector of Ami, approved wordmark, confirm launcher asset, review translations.
