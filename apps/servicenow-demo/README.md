# ServiceNow Employee Center demo
Front-end mock of the allNow Employee Center with Ami embedded. Open `index.html` with Live Server.

- No percentage loader; hero Ami spins in (cartoon pop) on every refresh.
- Hero Ami: cursor follow + hover. Navbar, search bar and chat Ami: calm, no blinking.
- Chat launcher: white circle, gold stars, blinks on click only.

This is a visual prototype, not a ServiceNow widget. Real assets are in `design-handoff/brand-assets`.
